## `mUnit.maude` — Test Engine

### `UNIT-RESULT` (functional module)
Defines the verdict record `op <_,_,_> : Nat Nat QidList -> UnitResult [ctor]` — correct count, failed count, and the report text (a `QidList` of tokens including color codes). Protects `QID-LIST`.

### `AUX` (functional module)
Metaterm and module-manipulation utilities used by the processor. Protects `META-LEVEL` and `CONVERSION`:

| Operation | Responsibility |
|---|---|
| `downQid`, `downQidList`, `downType`, `getStringType` | Convert metarepresented qids / type lists back to plain qids (strips the leading quote via `substr`) |
| `reduce : Module Term -> Term [memo]` | `getTerm(metaReduce(M, T))` — the workhorse behind all equational assertions |
| `rewrite : Module Term -> Term` | `getTerm(metaRewrite(M, T, unbounded))` |
| `solveBubbles [memo]` | Re-parse a bubble's token list in module `M` with `metaParse(M, QIL, anyType)` — the two-level-syntax resolver |
| `solveBubblesCond [memo]` | Parse a bubble as a search condition: `metaParse(..., '@Condition@)` then `parseCond` |
| `parseCond` | Convert a parsed condition metaterm into a META-LEVEL `Condition` (`_=_`, `_:_`, `_:=_`, `_=>_`, `_/\\_`); a bare term `T` becomes `T = 'true.Bool` |
| `addInfoConds : Module -> [Module]` | Extend the module under test with condition syntax: a constant per sort mapped into `'@Sort@`, `op '_:_ : S '@Sort@ -> '@Condition@`, connectives, and `Bool < '@Condition@` when `Bool` is present — enabling conditions like `T:BSTree` |
| `addOps`, `addSorts`, `addSubsorts`, `override` | Structural module surgery on metarepresented `fmod`/`mod` terms (accumulator pattern) |
| `printCond`, `printBound`, `printOpts` | Report formatting (conditions, bounds, pretty-print options) |

### `MUNIT-COMMAND-PROCESSING` (functional module)
The assertion interpreter. Protects `UNIT-RESULT` and `AUX`.

- `procMUnit : Term -> UnitResult` — entry point; destructures `'munit_is_endu['token[T], T']`, extracts the module name with `downTerm`, then:
  - `procMUnit : Qid Term -> UnitResult` — if `upModule(Q, true)` succeeds, runs `procProps(M, T')`; otherwise reports "The module is not loaded".
- `procProps : Module Term -> UnitResult` — dispatch on the assertion head symbol; recurses over `'__[T, T']` predlists summing the counters. One `ceq` family per verdict (pass / fail / no-parse / invalid-argument), plus an `[owise]` catch-all `< 0, 1, nil >`.
- `procSolution` / `noSolution : Module Term Term Qid Bound Condition -> UnitResult` — wrap `metaSearch(M, T, T', COND, Q, BND, 0)` (first solution suffices; `failure` decides pass/fail).
- `_notIn_ : Qid SortSet -> Bool` — membership test for `assertLeqSort`'s "sort does not exist" verdict.

Assertions handled: `assertTrue`, `assertFalse`, `assertTrueMsg`, `assertEqual`, `assertDifferent`, `assertReachable`, `assertReachableBnd`, `hasSolution`, `noSolution`, `assertSort`, `assertNoSort`, `assertLeqSort`.

## `io.maude` — REPL Front End

### `MAYBE{X :: TRIV}` + `view Term`
A parameterized optional-value container (`X$Elt < Maybe{X}`, constant `maybe`). The view maps `TRIV`'s `Elt` to `Term` (over `META-TERM`), giving `Maybe{Term}` used for the `input:` and `parsed:` attributes.

### `META-OPS`
`addImports : ImportList Module -> Module` — prepends imports to a metarepresented `fmod`/`mod`. Used to assemble the grammar modules from bubble-declaration seeds.

### `COMMANDS`
Datatype of REPL commands: `open_ : @Token@ -> @Command@`, `quit`, `q` (all `[ctor]`). Note: the path argument is a single token — paths with spaces are not supported.

### `META-COMMANDS-SIGN`
Builds `COMMANDS-GRAMMAR` as an `FModule` data term: a `token` bubble operator (`id-hook('Bubble, '1 '1)`) over `QID`, imported into `COMMANDS`. Used by `[parse-command]` / `[parse-command-error]` via `metaParse(COMMANDS-GRAMMAR, tokenize(S), '@Command@)`.

### `MUNIT-SIGNATURE`
The top-level test syntax, one `[ctor]` operator per assertion plus the `[assoc]` predlist `__` and `munit_is_endu : @Token@ @MUnitPredList@ -> @MUnitModule@`. Declaration order/attributes matter: `assertEqual`/`assertDifferent` carry `[comm]` (argument order-insensitive declarations).

### `META-MUNIT-SIGN`
Builds `MUNIT-GRAMMAR` as an `FModule`: `token` (length-1 bubble), `neTokenList`, and `bubble` (`id-hook('Bubble, '1 '-1 '`( '`))` with `id-hook('Exclude, ...)` listing Maude keywords that terminate a bubble). `MUNIT-GRAMMAR = addImports((including 'MUNIT-SIGNATURE .), BUBBLES)`.

### `MUNIT-IO` (system module)
The session. Elements:
- **Attributes**: `input:`/`parsed:` (`Maybe{Term}`), `state:` (`State`), `data:` (`String`, the accumulating file text).
- **States**: `idle`, `waiting`, `reading`, `processing`, `executing`, `write&wait`, `write&end`, `finished`.
- **Messages/strings**: `errorMsg`, `noParseMsg`, `byeMsg`, `mu-banner`, `printUR : UnitResult -> String` (the totals + per-test report), `printRed`.
- **Object identifiers**: `op munit : -> Oid`, `op MUnit : -> Cid`.
- **Rules**: `open-cmnd-start/opened/got-line/closed` (file reading), `parse-module`, `execute`, `remove-wrote-wait/end`, `quite-large`/`quit-short`, `parse-command`/`parse-command-error`.
- **Initial state**: `initAtS` + `run` (portal + object + banner write), driven by `erew run .`; the trailing `eof` ends the file, leaving the last lines dead code (see `review_notes.md`).
