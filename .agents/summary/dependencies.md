# MUnit — Dependencies

> External dependencies and their usage. Generated by codebase-summary.

## Runtime Dependency

| Dependency | Version | Usage |
|---|---|---|
| Maude interpreter | 3.5.1 (verified; binary built Jul 16 2025) | The only runtime. MUnit is Maude source loaded directly — no build step, no package manager |
| Maude launch flag | `-allow-files` | Required: `open` uses the `FILE` external object, disabled by default |

## Maude Prelude Modules Consumed

| Prelude module | Used for | Where |
|---|---|---|
| `META-LEVEL` (incl. `META-TERM`, `META-MODULE`, `META-CONDITION`, `META-STRATEGY`) | `upModule`, `metaParse`, `metaReduce`, `metaRewrite`, `metaSearch`, `metaPrettyPrint`, `getTerm`, `getName`, `getSorts`, `sortLeq`, `sameKind`; metaterm/module/condition data sorts | `AUX`, `MUNIT-COMMAND-PROCESSING`, grammar modules |
| `CONVERSION` | `upTerm`/`downTerm` between levels; `string`/`rat` conversions | `AUX`, `MUNIT-IO` |
| `LEXICAL` | `tokenize` (String → QidList), `printTokens` (QidList → String, understands color tokens) | `MUNIT-IO`, `AUX` |
| `QID-LIST`, `QID` | Token lists and quoted identifiers everywhere (reports, bubbles) | all modules |
| `NAT`, `BOOL` | Counters, verdict comparisons, `Bound` | `UNIT-RESULT`, `AUX`, `MUNIT-COMMAND-PROCESSING` |
| `STRING` | File/text accumulation (`data:`), messages, banners, `substr`/`length` in `downQid` | `AUX`, `MUNIT-IO` |
| `STD-STREAM` | `stdin`/`stdout` external objects; `getLine`/`gotLine`, `write`/`wrote` | `MUNIT-IO` |
| `FILE` | `fileManager`; `openFile`/`openedFile`, `getLine`, `closeFile`/`closedFile` (and the unhandled `fileError`) | `MUNIT-IO` |
| `CONFIGURATION` (object-oriented layer) | `Oid`, `Cid`, object/class syntax, messages, `Portal` constant `<>` | `MUNIT-IO` |
| `TRIV`, `META-TERM` (theories/views) | `MAYBE{X :: TRIV}` parameterization; `view Term` | `io.maude` |

## Version-Sensitivity Notes

- The bubble mechanism (`special(id-hook('Bubble, ...) op-hook(...))`), `STD-STREAM`/`FILE` external objects, and META-LEVEL descent-function signatures are stable across Maude 3.x, but the tool is developed against Maude 3.5.1; behavior of any other version is unverified.
- `print conceal` / `set print attribute off` (used in the dead tail of `io.maude`) are Maude 3.x commands.
- No third-party Maude libraries; no dependencies outside the Maude distribution.
- Distribution via git (GitHub); no CI, no test runner — the `examples/` files double as manual tests.
